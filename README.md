# Visual Analysis

Visual Analysis 是 Windows 11 x64 原生视觉分析应用。解压发布包后打开 `VisualAnalysis.exe`。模型优先使用本机 DirectX 12 显卡，推理运行库和模型随包提供。

| 一级入口 | 用途 |
| --- | --- |
| 人像检索 | 混选本机照片、视频查库，也可打开摄像头。按人员库、性别、地区码与年龄筛选。 |
| 目标查找 | 目标检测支持标注视频、目标截图和穿线或入区抓拍。以图搜索按外观或人脸比对。语义搜索支持人物衣着和车辆颜色。 |
| 车辆分析 | 车牌识别支持图片、视频及手动选区，展示原始裁图、可用的还原图和识读结果。车型识别可查询公开参考图及资料。 |
| 人像工具 | 双照比对。人像还原页面显示「开发中」。 |
| 警情筛选 | 本机导入 110 当日警情 .xlsx，核对命中依据和冲突证据，再导出筛选结果。 |
| 资料库 | 管理人员、特征、关联与排除标注，导出标注和素材。 |

车型识别由独立进程联网，查询只发送候选文字。其余功能在本机运行。设置、人员与标注数据继续使用 `%LOCALAPPDATA%\FaceMatching`。[默认车型来源与图库格式](docs/vehicle-catalogues.md)
