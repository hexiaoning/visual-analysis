# Visual Analysis

Visual Analysis 是 Windows 11 x64 原生视觉分析应用。解压发布包后打开 `VisualAnalysis.exe`。模型优先使用本机 DirectX 12 显卡，推理运行库和模型随包提供。

| 功能 | 使用方法 |
| --- | --- |
| 图像还原 | 选择照片或人像视频。照片按原图一致性、可辨的细节差异和残留碎纹筛选候选。只在有可靠差异时给第二张。 |
| 视频车牌 | 选起始视频帧，框选车牌。导出多帧融合、去拖影候选及实际使用的原始选区。 |
| 人脸检索 | 两张照片对比、在选定人员库中找照片候选，或在本机视频里检索。可按人员库和身份证的性别、地区码、年龄条件筛选。 |
| 人车检测 | 检测图片与视频中的人和车辆，可导出原始目标截图及带检测框的 MP4。在源视频首帧画触发线或框选区域，目标穿线或入区时保存整帧截图。 |
| 以图搜索 | 框选参考目标，在本机素材中做外观或人脸特征检索。 |
| 语义搜索 | 可以搜索「蓝色裤子的人」或「白色的车」。衣着条件按同一人物的相应区域比较。结果可预览、播放和导出。 |
| 车型识别 | 从本机图片或视频提出车系候选，实时查公开来源，再用参考图复核。支持本地参考图库。 |
| 人员库与标注库 | 支持录入、分类、特征重建、关联与排除标注，以及标注和素材 ZIP 导出。 |

车型识别由独立进程联网，查询只发送候选文字。其余功能在本机运行。设置、人员与标注数据继续使用 `%LOCALAPPDATA%\FaceMatching`。[默认车型来源与图库格式](docs/vehicle-catalogues.md)
